# 02 — Entry model

All types in §1–§8 live in **YFex core, namespace `YFex.Auditing`** (⚑A2) unless noted. They have no dependencies besides other
core namespaces (`YFex.Diagnostics` for trace/outcome/descriptors, `YFex.Privacy` declarations for sensitivity, `YFex` values for
`RawValue`/`IRawValue<T>`/`FieldPath`/`StableHash64`).

## 0. Vocabulary

| Term | Meaning | Example |
|---|---|---|
| **Audit entry** | One immutable business fact: who did what, to which targets, with which outcome | "joao finalized sale V-88123 at acme/loja7, ok" |
| **Action** | App-declared name of what was done; stable across releases | `Vendas.FinalizarVenda`, `Produto.Changed`, `Rules.Published` |
| **Category** | App-declared grouping that drives retention, permissions and filters | `DataChange`, `Security`, `fiscal`, `cash` |
| **Actor** | The identity the system acted for (**effective** principal) | user `joao` |
| **Real actor** | Who actually caused it when different from the actor | support user `sup-02` impersonating `joao`; the AI agent's sponsor |
| **Target** | An entity the action touched: entity type + key | `Produto` / `7891234567895` |
| **Change** | A field-level before/after on one target | `Preco: 10,00 → 12,00` |
| **Scope** | The in-flight collector of one entry (ambient, pooled) | — |
| **Journal** | The durable local append log on a node | SQLite on the POS |
| **Inbox** | Entries stored on the server (idempotently, by id) but not sealed yet | rows of `audit.entries` without a seal (07 §2) |
| **Chain** | The hash-linked sequence of sealed entries for one (tenant, retention class, UTC day) | `acme · fiscal-5y · 2026-10-01` |
| **Seal** | The server's assignment of chain index + hash to an entry | — |
| **Anchor** | A signed checkpoint `(chain, index, hash)` | every 1 000 entries / 10 min |
| **Day seal** | The final anchor of a chain day, with the Merkle root of its entries | — |
| **Tombstone** | A signed record that a chain day was purged by retention | — |

## 1. Shape of an entry (decoded view)

```csharp
// (sketch) decoded, cold-path read model (server queries, verifier, tests). Producers never build this object:
// they write through AuditScope/ChangeWriter straight into canonical bytes (§9).
public sealed class AuditEntry
{
    // identity & ordering
    public AuditEntryId Id { get; }                      // UUID v7, generated by the producing node (idempotency key, 05 §7)
    public Guid NodeId { get; }                          // NodeIdentity.InstanceId of the producer (shared with logging, logging 02 §6)
    public ulong NodeSequence { get; }                   // per node, gap-free: gap detection (06 §3)
    public DateTimeOffset OccurredAt { get; }            // producer clock (UTC)
    public DateTimeOffset? RecordedAt { get; }           // server inbox time (null on a device before shipping)

    // who / where
    public AuditActor Actor { get; }                     // effective principal
    public AuditActor? RealActor { get; }                // when Relation != None
    public ActorRelation Relation { get; }
    public string TenantPath { get; }                    // canonical ScopeIdentity text, e.g. "acme/loja7" ("" = single-tenant)
    public string? SessionId { get; }                    // pseudonymous session id (never a token)
    public string? DeviceId { get; }                     // POS / desktop device id

    // what
    public AuditAction Action { get; }
    public AuditCategory Category { get; }
    public OperationOutcome Outcome { get; }             // YFex.Diagnostics (shared with logging): Ok, Queued, Rejected, Denied, Conflict…
    public string? OutcomeCode { get; }                  // "AUTH.PERMISSION", "VAL.REQUIRED", "SEFAZ.539"
    public AuditEntryFlags Flags { get; }
    public ImmutableArray<AuditTargetChanges> Targets { get; }   // each target with its field changes (§5)
    public ImmutableArray<AuditField> Fields { get; }    // captured message fields (03 §3), already treated per sensitivity (08 §2)

    // why / approved by
    public AuditReason? Reason { get; }                  // reason code (app-declared) + scrubbed free text
    public ImmutableArray<AuditApproval> Approvals { get; }
    public AuditDecision? Decision { get; }              // rule set decision summary (Rules), if any

    // correlation
    public TraceId TraceId { get; }                      // YFex.Diagnostics; never empty (05 §1)
    public OperationId OperationId { get; }
    public AuditEntryId? ParentId { get; }               // entry of the enclosing audited operation (nested commands)
    public Guid? IdempotencyKey { get; }                 // outbox key of an offline-queued command (05 §8)
    public AuditEntryId? IntentId { get; }               // two-phase: the intent this outcome closes (05 §4)

    // sealing (server)
    public AuditSeal? Seal { get; }                      // chain key, index, hash, previous hash; null until sealed
    public ReadOnlyMemory<byte> CanonicalBytes { get; }  // the hashed truth (§9)
}
```

## 2. Identity, action, category

```csharp
namespace YFex.Auditing;

/// <summary>UUID v7 (time-ordered, Guid.CreateVersion7) generated by the producer. Also the idempotency key of the entry.</summary>
public readonly record struct AuditEntryId(Guid Value)
{
    public static AuditEntryId NewId() => new(global::System.Guid.CreateVersion7());
    public int FormatShort(Span<char> destination8);     // "4f1c9a2e" — the support/display code, like logging's support code
}

/// <summary>
/// What was done. App-declared (open set). Generated as static fields by the Cqrs/Audit generators; Id is
/// (uint)StableHash64(Name) so filters and indexes use an int, and renames are explicit ([AuditName("Old.Name")]).
/// </summary>
public readonly record struct AuditAction(string Name, uint Id)
{
    public static AuditAction Of(string name);           // computes Id; used by generated code in static initializers only
}

/// <summary>App-declared grouping (open set) that maps to a retention class, permissions and filters.</summary>
public readonly record struct AuditCategory(string Name)
{
    // Well-known categories owned by the framework (the library emits these itself). Apps add their own ("fiscal", "cash").
    public static readonly AuditCategory DataChange     = new("data-change");
    public static readonly AuditCategory Security       = new("security");       // denials, impersonation, credentials, webhooks rejected
    public static readonly AuditCategory Access         = new("access");         // read audit, audit-of-audit (08 §7)
    public static readonly AuditCategory Administration = new("administration"); // jobs/hub governance, rule publishing, settings
    public static readonly AuditCategory Privacy        = new("privacy");        // erasure, export, consent-related operations (YFex.Privacy)
    public static readonly AuditCategory Synchronization= new("synchronization");// sync failures acknowledged, outbox overflow
}
```

An app **declares** its categories once (with their retention class, 08 §5) so the generator can check the names used in
`.Audit(a => a.Category("fiscal"))`:

```csharp
[AuditCategories]
public static partial class FarmaAudit
{
    public static readonly AuditCategory Fiscal   = new("fiscal");      // → retention class "fiscal-5y" (configured, 08 §5)
    public static readonly AuditCategory Cash     = new("cash");
    public static readonly AuditCategory Controlled = new("controlled-substances");
}
```

## 3. Actor, real actor, relation (⚑A4, ⚑A26)

Two different things are called "impersonation" in the ecosystem today, and an AI agent adds a third:

| Situation | Actor (effective) | Real actor | Relation |
|---|---|---|---|
| Normal request | `joao` | — | `None` |
| Platform admin acts **inside another tenant** (YFex.Web `X-Tenant-Impersonate` header) | `admin-7` (same user) | `admin-7` with **home tenant** `platform` | `TenantImpersonation` |
| Support **logs in as a user** to reproduce a problem | `joao` | `sup-02` | `UserImpersonation` |
| Manager authorizes an operation **on behalf of** a cashier (delegated session) | `caixa-3` | `ger-01` | `Delegation` |
| AI agent executes a tool call started by a user | `agent:pricing-assistant` (`Agent`) | `maria` (the human who started it) | `AgentOnBehalf` |
| Scheduled job | `job:estoque.reprocessar` (`Job`) | the user who scheduled/overrode it, if known | `Delegation` or `None` |

**The actor types live in YFex.Actors** (actors AC1, 2026-11-05; atlas F05). Audit's own `AuditActorKind`, `AuditActor` and
`ActorRelation` were deleted; entries hold `YFex.Actors.ActorIdentity`, and the codec writes its canonical bytes. The model is in
`../actors/02-model-and-core-types.md`; in short:

```csharp
using YFex.Actors;

// kind numbers = this design's former AuditActorKind numbering (⚑AC2 / ⚑RA10): Anonymous 0 … System 6
ActorIdentity cashier = ActorIdentity.User("8f3a2c", TenancyPath.Parse("0=farmaviva/1=loja7"));   // never a name or e-mail
ActorIdentity job     = jobKey.ToActor(home);                                                    // YFex.Jobs' JobKey (⚑AC14)

// ambient actor: actor, real actor, relation, session and origin (the installation where the work started, ⚑AC16)
ActorScope? who = ActorContext.Current;
ActorSnapshot stored = ActorContext.Capture();          // outbox rows, job queues, offline envelopes
using (ActorContext.Restore(stored)) { /* replay */ }   // keeps the original origin
```

`IAuditActorSource` stays as the fallback when no scope is ambient (`TryGetActor(out ActorIdentity actor, out ActorIdentity? realActor,
out ActorRelation relation)`); the engine reads `ActorContext.Current` first (actor, real actor, relation, session id).

Who sets it (one writer per host; libraries only read `ActorContext.Current`):

| Host | Writer |
|---|---|
| YFex.Authorization `YFexAuthorizationMiddleware` (HTTP) | Enters `caller.ToActorScope(origin)` for the request; origin = the installation the token is bound to |
| Messaging.Rpc `CallContext` | Enters the call's scope; origin = YFex.Installations.Rpc's asserted installation (`ICallOriginSource`), else the token's bound installation |
| Desktop / POS sign-in | `AmbientPrincipalAccessor` / `SnapshotPrincipalAccessor` set the session scope; origin = the local installation |
| YFex.Jobs dispatcher | Each run enters its job actor (`jobKey.ToActor(scope)`), origin = the scheduler's installation; run-as is Plan D2b |
| Offline replay at central | Restores the envelope's actor with the terminal as origin (the replay itself is Offline provenance) |
| Automation agent loop | `Agent` actor; real actor = the trigger's user (`ActorScope.OnBehalf`) |

## 4. Tenant scope

- `TenantPath` = canonical text of the effective `ScopeIdentity` (YFex.Tenancy) at the time of the action, e.g. `acme/loja7/caixa3` if the
  app's scope chain has three rungs. The engine resolves it once per entry (YFex.Audit → YFex.Tenancy). Core only carries the string.
- The **chain tenant** is the top-level rung (`acme`). Chains are per top-level tenant (06 §4) so a store-level admin reading
  `acme/loja7` still verifies against the tenant's single chain per day/class.
- Single-tenant apps use `""`.
- The entry stores the tenant **as it was**, so an entry survives tenant renames (the store resolves display names at read time, like actors).

## 5. Targets and field changes

```csharp
/// <summary>An entity touched by the action. EntityType is app-declared (from [AuditEntity] or the convention of 04 §2).</summary>
public readonly record struct AuditTarget(string EntityType, string Key);

/// <summary>Closed set.</summary>
public enum ChangeKind : byte
{
    None = 0,         // target referenced, nothing changed (e.g. the sale a cash withdrawal points at)
    Created = 1, Updated = 2, Deleted = 3,
    ItemAdded = 4, ItemRemoved = 5, ItemMoved = 6, ItemUpdated = 7,   // inside a collection member
}

/// <summary>How a value is stored in the entry (08 §2). Closed set.</summary>
public enum ValueTreatment : byte
{
    Clear = 0,          // Public / Internal
    Pseudonymized = 1,  // HMAC pseudonym (YFex.Privacy) — joinable, not reversible
    Encrypted = 2,      // AES-GCM envelope with a subject/category key (YFex.Privacy) — reversible by audit.reveal, crypto-shreddable
    Tokenized = 3,      // token-vault reference (Financial)
    Digest = 4,         // SHA-256 of a large value (blob, XML document) — proves identity of content without storing it
    Erased = 5,         // Secret / Financial without token: "a value existed and changed"
    Omitted = 6,        // collections beyond the cap, binary data: count/length only
}

// (sketch) decoded read model
public sealed record AuditTargetChanges(AuditTarget Target, ChangeKind Kind, ImmutableArray<FieldChange> Changes);
public sealed record FieldChange(FieldPath Path, ChangeKind Kind, AuditValue Before, AuditValue After);
public readonly record struct AuditValue(ValueTreatment Treatment, RawValue Value, ReadOnlyMemory<byte> Protected, DataSensitivity Sensitivity);
public sealed record AuditField(string Name, AuditValue Value);                                  // captured message field
public readonly record struct AuditSeal(string Tenant, string RetentionClass, DateOnly Day, ulong Index,
    Hash256 PreviousHash, Hash256 Hash, DateTimeOffset SealedAt);                                // server chain position (06 §4)
```

- `FieldPath` (YFex core `Paths/FieldPath.cs`) is reused: `Preco`, `Itens[3].Quantidade`, `rows[0f6c…].faixa` (rule tables).
- Values are **typed** (`RawValue`: number, decimal, date, Guid, text, typed `Money`/`Quantity` via `IRawValue<T>`), never strings formatted on
  the producer. The history panel formats them per culture at read time (09 §3).
- Enum values are stored **by name** (generated name tables) plus the numeric value, so renumbering an enum never corrupts history.

## 6. Reason, approvals, rule decisions

```csharp
/// <summary>Why: an app-declared reason code ("devolucao.cliente") and/or free text typed by the user (scrubbed by YFex.Privacy).</summary>
public readonly record struct AuditReason(string? Code, string? Text);

public enum ApprovalSource : byte { Server = 0, Device = 1, Inline = 2 /* approver re-authenticated on the same screen */ }

/// <summary>An approval that authorized the action (YFex.Rules override tokens map 1:1; other approval systems can produce it too).</summary>
public readonly record struct AuditApproval(string ApproverId, string Permission, ApprovalSource Source, string KeyId,
    ulong DecisionFingerprint, DateTimeOffset IssuedAt);

/// <summary>Summary of a rule decision that governed the action (YFex.Rules writes it; strings keep core free of Rules types).</summary>
public readonly record struct AuditDecision(string RuleSet, long Version, ulong Fingerprint, string Verdict,
    int AppliedAdjustments, bool Flagged);
```

The Cqrs `RulesStage` writes `AuditDecision` and every accepted `AuditApproval` into `AuditScope.Current` (one null check when the
message is not audited). A **flagged** decision sets `AuditEntryFlags.NeedsReview`, which feeds the review queue (09 §5). This replaces
`IDecisionAuditSink` (01 §3).

## 7. Flags and links

```csharp
[Flags]
public enum AuditEntryFlags : ushort
{
    None = 0,
    NeedsReview  = 1,     // flagged decision, offline approval, out-of-band change: shows in the review queue
    Implicit     = 2,     // created by an [AuditChanges] write outside any audited scope (04 §8)
    OutOfBand    = 4,     // captured by the database trigger mode with no app audit context (04 §4)
    Intent       = 8,     // two-phase: the intent half (05 §4)
    Outcome      = 16,    // two-phase: the outcome half (IntentId set)
    Continuation = 32,    // a large change set split across entries (ParentId = first entry, 04 §6)
    Coalesced    = 64,    // repeated identical denials folded into one entry with a count field (03 §6)
    Offline      = 128,   // produced while the node was offline (shipping delayed)
    Amendment    = 256,   // corrects the outcome of an entry already committed transactionally (05 §2.3)
}
```

Correlation is always present: `TraceId` (from `TraceContext.Current` when YFex.Logging runs; otherwise the engine starts its own trace id
for the root audited operation, so nested entries still share one), `OperationId`, `ParentId` (nested audited operations),
`IdempotencyKey` (offline replay), `IntentId` (two-phase).

## 9. Canonical encoding v1 (⚑A20)

The entry is encoded **once** by the producer into canonical bytes. Those bytes are journaled, shipped, stored (`audit.entries.entry`),
hashed into the node chain and the server chain, and re-hashed by the offline verifier. Nothing ever hashes JSON.

```
entry      = magic "YAE" u8 version(=1)  section*            (sections in strictly increasing tag order; each at most once
                                                              except 0x20 targets and 0x30 fields, which repeat in emission order)
section    = u8 tag  varint length  payload
tags       : 0x01 identity   (16 B entry id, 16 B node id, u64 node sequence, i64 occurred UTC ticks)
             0x02 actor      (u8 kind, str id, str? home tenant)        0x03 real actor (same) + u8 relation
             0x04 tenant     (str tenant path)                          0x05 session/device (str?, str?)
             0x06 action     (u32 id, str name, str category)
             0x07 outcome    (u8 outcome, str? code, u16 flags)
             0x08 trace      (16 B trace id, 8 B operation id, 16 B? parent entry, 16 B? idempotency key, 16 B? intent id)
             0x10 reason     (str? code, str? text)
             0x11 approval   (str approver, str permission, u8 source, str key id, u64 fingerprint, i64 issued ticks)   (repeats)
             0x12 decision   (str rule set, i64 version, u64 fingerprint, str verdict, i32 adjustments, u8 flagged)
             0x20 target     (str entity type, str key, u8 change kind, u16 change count) followed by change*
             0x30 field      (str name, value)
change     = str path  u8 kind  value(before)  value(after)
value      = u8 treatment  u8 sensitivity  u8 value kind  payload    (RawValue parts: fixed-width little-endian numbers, decimal as
             its 4 int32 bits normalized (no trailing zeros), dates as UTC ticks, text as UTF-8 NFC; Encrypted/Tokenized/Digest:
             length-prefixed bytes; Erased/Omitted: u32 count/length only)
str        = varint byte length, UTF-8 (NFC normalized), no BOM
```

Rules that make it canonical: fixed tag order, one encoding per value kind, normalized decimals and strings, no floating-point
formatting (doubles as IEEE bits), UTC ticks only, no optional padding. The decoder rejects anything non-canonical (so two encoders can
never disagree about the same entry). The format is **versioned**: the verifier keeps readers for every version ever written.

Size: a typical command entry with 1 target, 3 field changes and 5 captured fields is ~350–600 bytes.
