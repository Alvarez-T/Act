# 02 — Schema model

All types live in `YFex.Data` (single namespace `YFex.Data`, folder `src/YFex.Data/Schema/`), replace the current
`Schema/` types (⚑DS1). Names are own value types (`SqlIdentifier`, `SqlTableName`, `SchemaModuleName`,
`SchemaVersionNumber`; [09 §1](09-library-conventions.md#1-own-types)); `TableRef`/`ColumnRef` remain for DataMining interop. They are plain immutable objects built in code, so they are
AOT-safe, need no attributes and no reflection, and are built once (a `static` property) per module.

## 1. `ColumnType`: portable column types

> Named `ColumnType` in the code (this document said `DataType` until DS-P1): `System.ComponentModel.DataAnnotations.DataType`
> is imported by the row classes that carry `[MaxLength]` (DS-P4), and the same simple name would be ambiguous there (CS0104).

The kind **reuses `BulkColumnType`**, the portable type set YFex.Data already maps for bulk writes on every engine. A
`TableSchema` therefore becomes a `BulkTable` without a second type table. `ColumnType` adds what DDL needs on top of it:
length, precision/scale, ASCII-only.

```csharp
// (sketch)
public readonly record struct ColumnType
{
    public BulkColumnType Kind { get; }
    public int? MaxLength { get; }        // String, AsciiString, Binary; null = unbounded
    public byte? Precision { get; }       // Decimal
    public byte? Scale { get; }           // Decimal
    public bool IsAscii { get; }          // String only: non-Unicode storage where the engine distinguishes (SQL Server varchar)

    public static ColumnType Boolean { get; }
    public static ColumnType Int16 { get; }
    public static ColumnType Int32 { get; }
    public static ColumnType Int64 { get; }
    public static ColumnType Double { get; }
    public static ColumnType Guid { get; }
    public static ColumnType DateTime { get; }         // no offset
    public static ColumnType DateTimeOffset { get; }   // an instant
    public static ColumnType Json { get; }
    public static ColumnType Decimal(byte precision, byte scale);
    public static ColumnType String(int? maxLength = null);       // Unicode text
    public static ColumnType AsciiString(int maxLength);           // ids, codes, provider names
    public static ColumnType Binary(int? maxLength = null);
}
```

Rules:

- `String()` / `Binary()` with no length means **unbounded**. Unbounded types cannot be part of a primary key or an
  index (validation YFSCH002). This is what forces Offline's `key` columns to say `String(450)`, which SQL Server already
  needs today.
- A bounded length is **enforced on every engine** (⚑DS3). The same value is accepted or rejected everywhere.
- No engine type names in the model. A column that truly needs `money`, `hstore` or `geography` uses a `SqlStep`
  ([04 §5](04-migrations-and-versioning.md#5-the-escape-hatch-sqlstep)) and is outside the portable contract.

## 2. Columns, keys, indexes, foreign keys

```csharp
// (sketch)
public sealed class ColumnSchema
{
    public SqlIdentifier Name { get; }
    public ColumnType Type { get; }
    public bool IsNullable { get; }                // default false: a column is NOT NULL unless declared otherwise
    public ColumnDefault? Default { get; }         // literals only (number, text, boolean); no engine functions
    public bool IsIdentity { get; }                // Int32/Int64 only: generated by the database
}

public readonly record struct ColumnDefault   // (sketch) Literal(long) | Literal(string) | Literal(bool)

public sealed class PrimaryKeySchema  { SqlIdentifier? Name; ReadOnlySpan<SqlIdentifier> Columns; }   // Name null → "pk_{table}"

public sealed class IndexSchema
{
    public SqlIdentifier Name { get; }
    public ReadOnlySpan<IndexColumn> Columns { get; }     // IndexColumn(SqlIdentifier Name, bool Descending = false)
    public bool IsUnique { get; }
}

public sealed class ForeignKeySchema { SqlIdentifier Name; ReadOnlySpan<SqlIdentifier> Columns; SqlTableName Principal;
                                       ReadOnlySpan<SqlIdentifier> PrincipalColumns; ReferentialAction OnDelete; }
public enum ReferentialAction : byte { NoAction, Cascade, SetNull }
```

**One portable meaning for unique indexes:** two rows never collide when the indexed value **contains a NULL**. That is
the SQL standard, and the default on PostgreSQL and SQLite. Dialects whose engine behaves otherwise compensate:
SQL Server with a filtered index, Oracle with a function-based index ([03 §4](03-ddl-dialects-and-rendering.md#4-semantic-features-the-dialect-must-honour)).
Today `AuthenticationSqlSchema` encodes this by hand for SQL Server only. With the model it is the default and needs
no flag.

Not in the model (not portable; use a `SqlStep`): check constraints, partial indexes with arbitrary predicates,
computed columns, collations, triggers, partitioning, tablespaces/filegroups.

## 3. `TableSchema`

```csharp
// (sketch)
public sealed class TableSchema
{
    public SqlTableName Table { get; }                  // no schema = the connection's default schema; ToTableRef() for DataMining
    public ReadOnlySpan<ColumnSchema> Columns { get; }    // spans over private arrays (09 §1.4)
    public PrimaryKeySchema? PrimaryKey { get; }
    public ReadOnlySpan<IndexSchema> Indexes { get; }
    public ReadOnlySpan<ForeignKeySchema> ForeignKeys { get; }

    public static TableSchema Create(string name, Action<TableSchemaBuilder> build);   // parsed to SqlTableName immediately
    public static TableSchema Create(SqlTableName table, Action<TableSchemaBuilder> build);

    public int IndexOf(SqlIdentifier column);           // case-insensitive linear scan, -1 when absent
    public BulkTable ToBulkTable();                     // every non-identity column, in declaration order
    public BulkTable ToBulkTable(params ReadOnlySpan<string> columns);
}
```

Builder, shown on a real Offline table (today's line in `OfflineSqlSchema` in the comment):

```csharp
// (sketch)
// create table offline_receipts (idempotency_key {id} not null primary key, outcome {small} not null,
//   error_kind {small} not null, detail {longText} null, findings {number} not null, processed_at {number} not null)
// create index ix_offline_receipts_processed on offline_receipts (processed_at)
public static TableSchema Receipts { get; } = TableSchema.Create("offline_receipts", t => t
    .Column("idempotency_key", ColumnType.AsciiString(36)).PrimaryKey()
    .Column("outcome", ColumnType.Int16)
    .Column("error_kind", ColumnType.Int16)
    .Column("detail", ColumnType.String(), nullable: true)
    .Column("findings", ColumnType.Int64)
    .Column("processed_at", ColumnType.Int64)
    .Index("ix_offline_receipts_processed", "processed_at"));
```

Composite keys: `.PrimaryKey("stream", "version", "subject", "idempotency_key")`. Unique index:
`.UniqueIndex("ux_authentication_operator_codes", "realm", "operator_code")`.

## 4. `SchemaModule`: the unit a library owns

A module is a **named, versioned** set of tables: one per library (`yfex.offline`, `yfex.authentication`,
`yfex.rules`). Several modules share one database, and each has its own version line in the history table
([04](04-migrations-and-versioning.md)).

```csharp
// (sketch)
public sealed class SchemaModule
{
    public SchemaModule(SchemaModuleName name);          // lower-case, dotted: "yfex.offline"
    public SchemaModuleName Name { get; }
    public ReadOnlySpan<SchemaVersion> Versions { get; } // ascending, contiguous from 1
    public int LatestVersion { get; }
    public SchemaState Current { get; }                  // every step replayed in memory: the tables as they are at LatestVersion

    public SchemaModule Version(SchemaVersionNumber version, string description, Action<SchemaStepBuilder> steps);
}

public sealed class SchemaVersion { SchemaVersionNumber Number; string Description; ReadOnlySpan<SchemaStep> Steps; Hash256 Checksum; }

public abstract class SchemaStep;   // closed set:
//   CreateTableStep(TableSchema)        DropTableStep(SqlTableName)
//   AddColumnStep(SqlTableName, ColumnSchema)  DropColumnStep(SqlTableName, SqlIdentifier)  RenameColumnStep(SqlTableName, SqlIdentifier, SqlIdentifier)
//   CreateIndexStep(SqlTableName, IndexSchema)  DropIndexStep(SqlTableName, SqlIdentifier)
//   AddForeignKeyStep / DropForeignKeyStep
//   SqlStep (explicit per-provider SQL, 04 §5)
//   RowSecurityStep(RowSecurityPolicy)   (03 §6)
```

`SchemaState Current` answers "what does `offline_receipts` look like now?" without a database. Stores build their
`BulkTable` from it, the EF bridge compares against it, and DS-P7 compares it with the live database.

`Checksum` is a `Hash256` (SHA-256) of the version's canonical step bytes, not of rendered SQL, so it is the same on every
engine ([09 §1.3](09-library-conventions.md#13-canonical-encoding--checksum)).
The migrator refuses to run when an applied version's checksum changed ([04 §3](04-migrations-and-versioning.md#3-applying-a-module)).

## 5. Validation

`SchemaValidator.Validate(SchemaModule module, ISchemaDialect dialect)` returns diagnostics. It runs in the migrator
before any statement and in each consumer's unit tests for **every** known dialect. That is how Offline learns its
schema would not work on Oracle without an Oracle database at hand.

| Code | Severity | Rule |
|---|---|---|
| YFSCH001 | error | identifier longer than the engine allows (PostgreSQL 63, **silently truncated**; Oracle 128, 30 before 12.2; SQL Server 128; MySQL 64) |
| YFSCH002 | error | a type the engine cannot index (unbounded `String`/`Binary`/`Json`; SQL Server `(max)`; Oracle `clob`/`blob`) in a primary key, index or foreign key |
| YFSCH003 | error | index/key wider than the engine's key limit (SQL Server 900 bytes clustered / 1,700 non-clustered; `nvarchar` counts 2 bytes per character) |
| YFSCH004 | error | identifier not portable: must match `[A-Za-z_][A-Za-z0-9_]*` and not be a reserved word of the dialect. Identifiers are written **unquoted** everywhere, as `BulkTable` and the stores already do |
| YFSCH005 | error | structure: a step that does not fit the replayed schema, a table/index/constraint name used twice **anywhere in the schema** (the strictest engine rule, applied to all), nullable primary-key column, a foreign key that does not reference a primary key/unique index of the same type. (Duplicate names inside one table, keys naming missing columns and identity on non-integers are rejected earlier, by the `TableSchema`/`ColumnSchema` constructors) |
| YFSCH006 | error | `SqlStep` without SQL for this dialect's provider |
| YFSCH007 | warning | `ColumnType` the engine stores lossily (SQLite: `DateTimeOffset` and `Decimal` as text). Decimal precision is capped at 38 by `ColumnType.Decimal` itself |
| YFSCH008 | error | a step the engine cannot run (SQLite: adding/dropping a foreign key on an existing table, a NOT NULL column added without a default, an identity column that is not the whole primary key) |
| YFSCH009 | warning | a NOT NULL column without a default is added: it fails when the table already has rows |

Test helper for consumers (in `YFex.Data`, no test framework dependency; it throws on errors):

```csharp
// (sketch)
SchemaAssert.Valid(OfflineSqlSchema.Module, SqliteDialect.Instance, PostgresDialect.Instance,
                   SqlServerDialect.Instance, OracleDialect.Instance);
```

## 6. Generated table schemas (DS-P4)

The fluent model above is the runtime model and the migration-step language. A source generator can also produce a
`TableSchema` from an attributed `partial` row class (the current shape of the table), together with typed column-name
constants, a `BulkTable` and an `IBulkRowMapper<T>`. Migration versions stay frozen fluent steps, and
`SchemaAssert.InSync` keeps the two in agreement. Evaluation and design:
[08 §6](08-evaluation-ef-vs-own-model-vs-generator.md#6-generators-what-they-add-and-what-they-cannot-do).
